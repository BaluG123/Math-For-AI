# 🧠 MathForAI — Zero to Hero Math Mastery for Artificial Intelligence

> **Master every mathematical concept needed to become a world-class AI practitioner.**

---

## 🎯 What Is This?

This is a **complete, hands-on mathematics curriculum** built specifically for AI mastery. It covers everything from foundational linear algebra to research-level differential geometry and measure theory — all with Python code, visualizations, and exercises.

**Format**: Each module contains 3 Jupyter notebooks:
- `01_Concepts.ipynb` — Theory (LaTeX) + Python implementations + visualizations
- `02_Exercises.ipynb` — 15+ practice problems (computational, proof-based, applied AI)
- `03_Solutions.ipynb` — Complete worked solutions

## 📖 Recommended Textbooks

1. **Linear Algebra**: *Linear Algebra and Its Applications* — Gilbert Strang
2. **Calculus**: *Calculus* — James Stewart
3. **Probability**: *Introduction to Probability* — Blitzstein & Hwang
4. **Optimization**: *Convex Optimization* — Boyd & Vandenberghe
5. **Information Theory**: *Elements of Information Theory* — Cover & Thomas
6. **Deep Learning Math**: *Mathematics for Machine Learning* — Deisenroth, Faisal, Ong
7. **Advanced**: *Pattern Recognition and Machine Learning* — Bishop
